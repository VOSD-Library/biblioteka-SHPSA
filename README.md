# Каталог библиотеки ШПСА

Веб-каталог книг библиотеки ШПСА (Милан, Италия).  
**Живой сайт:** [https://vosd-library.github.io/biblioteka-SHPSA/](https://vosd-library.github.io/biblioteka-SHPSA/)

---

## 📚 О проекте

Статический каталог библиотеки на **791 книгу**, с обложками, поиском, фильтрами и сортировкой.  
Работает на **GitHub Pages**, обновляется одной командой.

### Возможности

- 🔍 **Поиск** по названию, автору, разделу, тегам
- 🎯 **Фильтры**: раздел, год, язык, тип
- 📊 **Сортировка**: по автору, издательству, инвентарному номеру, году
- 🖼️ **Обложки** книг (с автоматическим сжатием)
- 🌙 **Тёмная тема**
- 📱 **Адаптивный дизайн** для мобильных
- 🕐 **Часы** (время по Риму)
